# Second Wind

A gentle daily companion for the first weeks after a mental health crisis: a greenhouse you tend by treating yourself well.

- Static web app (single `index.html`), installable to the home screen
- All personal data stays in the browser's local storage on the device. Nothing is sent to a server. Use Settings → Download a backup.
- Help now (988, Crisis Text Line, 911, your people, your safety plan) is on every screen.

Second Wind is not a therapist or a crisis service. If you are in danger, call or text 988, or call 911.
